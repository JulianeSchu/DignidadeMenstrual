# Projeto Dignidade Menstrual - Tecnologia Aplicada à Inclusão Digital

Este repositório contém o código-fonte e a documentação do projeto desenvolvido para a disciplina de Atividade Extensionista II do curso de CST em Análise e Desenvolvimento de Sistemas da UNINTER.

O site oficial do projeto, com o mapa interativo e informações educativas, pode ser acessado em:
https://julianeschu.github.io/DignidadeMenstrual/

## Sobre o Projeto
O objetivo central deste trabalho é promover a inclusão digital e o acesso à informação sobre o Programa Dignidade Menstrual do Governo Federal. O projeto foca no bairro Vargem do Bom Jesus, em Florianópolis - SC.

## Objetivos Principais

Informar: Divulgar os critérios e benefícios do programa de distribuição gratuita de absorventes.

Mapear: Disponibilizar um mapa interativo com os pontos de retirada para facilitar o acesso da comunidade feminina.

Educar: Prover conteúdo sobre saúde e higiene menstrual.

Inclusão Digital: Utilizar ferramentas tecnológicas para reduzir desigualdades sociais e de gênero.

## Tecnologias Utilizadas
Frontend: HTML5, CSS3, JavaScript (Interatividade e APIs de mapas).

Ciência de Dados: Python, Pandas (Tratamento dos dados brutos em .xlsx).

Visualização: Plotly/Leaflet (Geração de mapas de calor e densidade).
